NOTAS
-----

- Para el catálogo actual, ingresa al menos una oferta con proveedor y precio
  para que la tarjeta muestre esa información.
- La categoría debe existir previamente en service_category. Para los planes
  de fibra incluidos como ejemplo, se usa Internet Fibra Óptica.
- El mismo servicio no puede tener más de una oferta del mismo proveedor;
  la base de datos limita a una oferta por combinación de servicio y proveedor.
- La calificación y el número de reseñas se calculan desde las reseñas; no se
  ingresan como datos directos del servicio.
- La API actual solo permite consultar servicios. Esta ficha recopila los datos
  para cargarlos mediante SQL; no existe un formulario o endpoint para crearlos.
